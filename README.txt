남촌축산물백화점 - 가격 수정 가능한 홈페이지

1. script.js를 메모장 또는 VS Code로 엽니다.
2. 맨 위 PRODUCTS에서 원하는 상품을 찾습니다.
3. price: 39000처럼 숫자만 바꿉니다.
4. 저장 후 GitHub 저장소에 script.js를 다시 업로드하고 Commit changes 합니다.
5. 홈페이지에서 Ctrl+F5를 눌러 변경 가격을 확인합니다.

각 상품 사진은 assets/ 안의 별도 JPG 이미지입니다.
index.html, style.css, script.js, assets 폴더를 GitHub 저장소 루트에 업로드하세요.

지육·워터에이징 팝업은 첫 방문에 나타나며, 오늘 하루 보지 않기 기능이 있습니다.
메뉴 버튼에서 언제든 다시 열 수 있습니다.

주의: 시안의 가격은 예시입니다. 실제 판매가와 단위(100g/600g/1팩 등)를 확인한 뒤 게시하세요.
원본 시안의 사진을 상품별로 잘라 사용했기 때문에 개별 사진의 해상도는 원본 이미지 크기에 제한됩니다.
